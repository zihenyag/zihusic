你收藏的，

从一张专辑到整个音乐文件夹。紧凑列表、封面缩略图和快捷搜索，让常听的歌随时找得到。

02 / 同步歌词

每一句，
看得舒服。

同名歌词放在音频旁边，自动读取。固定字号、颜色高亮，翻译和长句也能完整展开。

  • 支持 ASS、LRC 和内嵌 LRC 歌词
  • 点击跳到那一句，滚轮自由浏览
  • 停下浏览 3 秒，平滑回到正在唱的位置
  • 本地缓存与后台预读，切歌更快显示

03 / 封面与标签

整理曲库，
也不用离开播放器。

双击歌曲名、歌手、专辑就能编辑。双击封面，换上喜欢的那一张。

  • 修改立即更新到播放器
  • 可将标签和封面写回本地音频文件

写回 FLAC 需安装 metaflac；MP3、M4A、AAC 需 ffmpeg。未安装时仍可在曲库内编辑。

v0.4.0 新增 / AIRPLAY · 实验功能

让另一台 Mac，
也一起唱。

同一网络中的 AirPlay 接收器自动接入。启动时只有本机出声，想在哪台播放，再轻轻勾选。

自动接入需辅助功能授权，接收端需开启 AirPlay 接收器。已在 Mac mini 与 MacBook Air 上验证；其他设备与网络的效果可能不同。不支持 iPad 接收。

  • 自动发现与接入App 打开后才上线的设备，也会再次检查。
  • 每台设备，独立控制分别调音量、停止或恢复，停止时保留连接。
  • 需要时，重新对齐“播放 → AirPlay 全同步”，也可手动校准本机延迟。
ZIHUSIC v0.4.0

从你的曲库开始。

macOS 14 或更新版本 · Apple Silicon

下载 v0.4.0 ↓查看源码 ↗
  1. 下载并解压打开 zihusic_app_v0.4.0.zip。
  2. 移入 Applications，再打开当前为临时签名构建，尚未经过 Apple 公证。
  3. 选择你的音乐文件夹使用 AirPlay 自动接入时，按提示授予辅助功能权限。
首次打开遇到 macOS 拦截？

在“系统设置 → 隐私与安全性”中找到 zihusic，选择“仍要打开”。如果明确提示应用“已损坏”，确认下载来自本项目 Release 后，可在终端执行：

xattr -dr com.apple.quarantine /Applications/zihusic.app

更新后若 AirPlay 自动接入失效，在“辅助功能”中移除旧的 zihusic 条目，再添加 Applications 中的新版本。
